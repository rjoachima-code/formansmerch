# formansmerch

Basic project scaffold for the `formansmerch` workspace.

## Files
- `index.html` – main HTML entry
- `script.js` / `script2.js` – JavaScript files
- `eslint.config.js` / `.eslintrc.json` – lint configuration
- `package.json` – npm metadata and scripts

## Setup
```bash
npm install
```

## Usage
Open `index.html` in a browser, or run project scripts from `package.json` if defined.

This README was added to document the current project structure.
